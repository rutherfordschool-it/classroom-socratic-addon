🚀 Google Workspace Marketplace Publishing Steps

Step 1: Deploy Web Server with HTTPS
Deploy this application to any cloud host (Cloud Run, Render, Vercel, Railway, etc.). Google Classroom requires valid TLS 1.2+ HTTPS and the configured CSP frame-ancestors 'self' https://classroom.google.com https://workspace.google.com;.
Step 2: Google Cloud Console Configuration
Enable the Google Classroom API and Google Workspace Marketplace SDK. Create an OAuth 2.0 Web Client ID with your domain.
Step 3: Register Classroom Add-on Extension Points
In the Google Workspace Marketplace SDK configuration, fill in the URLs configured in google-classroom-manifest.json: /attachment-discovery.html, /student-work.html, and /teacher-review.html.
Step 4: Domain Admin Install or Public Store Listing
School IT administrators can install the add-on domain-wide for all teachers and students via the Google Admin Console.
