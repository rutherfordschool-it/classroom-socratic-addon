How Google Classroom Add-ons Work

Why this looks like a simulator and how to open it in real Google Classroom

❓ Why does this page look like a simulator / separate app?

In Google Workspace, an Add-on is NOT a browser extension. Google Classroom Add-ons are web applications hosted on your server and embedded by Google Classroom inside secure <iframe> containers.

Because real Google Classroom (https://classroom.google.com) only loads HTTPS URLs from approved Workspace Marketplace listings, Google designed this official architecture so developers test locally using a Classroom Host Simulator before deploying.

📊 Where can I open the Google Classroom Gradebook?

Notice the top navigation header right above this page: Stream | Classwork | People | Grades.

Clicking the "Grades" tab opens the live Google Classroom Gradebook. When a teacher evaluates student work in SocratesAI and passes back the grade, Pavel Birulin's grade (95/100) syncs immediately into that gradebook!

🌐 How do I open it inside REAL Google Classroom (classroom.google.com)?

  1. Deploy this web server to an HTTPS domain (e.g. Google Cloud Run, Render, Vercel).
  2. In Google Cloud Console, enable the Google Workspace Marketplace SDK.
  3. Register the 3 URIs from google-classroom-manifest.json (Discovery, Student Work, Teacher Review).
  4. Open https://classroom.google.com, create an assignment, click "+ Add-ons", and select SocratesAI!
