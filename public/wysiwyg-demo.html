🧪 WYSIWYG-формулы: демо для проверки

Формулы оформляются прямо при наборе — в том же поле, без окошек и без Preview.

Просто печатайте: 5/ → дробь · x^ → степень · log36 → log₃(6) (после основания курсор сам переходит в аргумент; ← назад в основание, → снова в аргумент) · sin / cos / tan / ln → сразу в аргумент (а sin^2x → sin²(x)) · sqrt → √ · * → · · <= → ≤ · >= → ≥ · != → ≠
Выйти из формулы в обычный текст: Пробел (в конце формулы), →, Enter или Esc. Вернуться в формулу: клик по ней, или ← / → / Backspace рядом с ней.
Длинная формула с пробелами: кнопка ∑ Формула или Ctrl+M — тогда пробел не выходит из формулы (выход: → / Enter).
